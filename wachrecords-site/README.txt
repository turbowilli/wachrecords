WACH RECORDS — statische Website

Start: index.html

Vor Veröffentlichung anpassen:
1. contact.html — echte geschäftliche E-Mail-Adresse
2. impressum.html — vollständige Pflichtangaben
3. datenschutz.html — an den tatsächlich gewählten Hosting-Anbieter anpassen
4. magazine.html — Cover, Preis und Bestellweg ergänzen
5. exhibitions.html — Termine ergänzen
6. about.html — finalen persönlichen Text ergänzen

Technik:
- Keine Datenbank
- Keine externen Webfonts
- Kein Tracking / Analytics
- Keine Cookies durch die Website selbst
- Responsive Layout
- WebP + JPEG Bilddateien

Deployment:
Der komplette Inhalt dieses Ordners kann auf einen Static-Hosting-Anbieter geladen werden. Die Domain wachrecords.de bei United-Domains wird anschließend per DNS auf diesen Anbieter verwiesen.
